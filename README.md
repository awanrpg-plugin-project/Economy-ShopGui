# EconomyShopGui Plugin

## Deskripsi
Plugin Keren Economy Futuristik Untuk Server Menjadi Terlihat Bagus Dan Keren

### Fitur Utama
-✅ Tampilan Ui Tema Futuristik 

-✅ Canggih Dengan Custom Model ItemsAdder

-✅ /bagiuang untuk membagi uang kamu ke player lain

-✅ /peringkatuang untuk melihat kamu peringkat berapa

-✅ /beli dan /jual untuk membeli dan menjual barang yang ada di shop
